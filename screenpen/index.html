ScreenPen

画面の上に、そのままペンで書き込めるツールです。

ScreenPen.zip をダウンロード バージョン 0.9.0 ・ 約54MB ・ Windows 10 / 11（64ビット）

どんなツールか

画面共有で説明しているときに「ここです」と丸を付けたくて作りました。画面に書き込むツールは有料のものが多かったので、自分で作ることにしました。

  • ペン、蛍光ペン、直線・矢印・四角・楕円、文字が使えます。
  • カーソルのボタンを押すと、書いたものを残したまま普段のマウス操作に戻ります。PowerPoint のスライドショー中でも、スライド送りの邪魔をしません。
  • 範囲を選んでスクリーンショットを撮ると、書き込んだ線も一緒に保存されます。
  • 白い紙・黒い紙に描ける「ペイント」のウィンドウもあります。ホワイトボード代わりに使えます。

使い方

  1. ダウンロードした zip を展開し、中の screenpen-0.9.0 フォルダを、デスクトップやドキュメントなど好きな場所に置きます。インストールはいりません。設定ファイルがフォルダの中にできるので、Program Files の中は避けてください。
  2. フォルダの中の ScreenPen.exe をダブルクリックで起動します。ツールバーと、タスクトレイのアイコンが出ます。_internal フォルダも動かすのに必要なので、exe だけ取り出さずフォルダごと使ってください。
  3. ペンのボタンを押すと書けるようになります。カーソルのボタンで元のマウス操作に戻ります。
  4. 終わるときは、ツールバー左端のロゴを押して「終了」を選ぶか、タスクトレイのアイコンを右クリックして終了します。

はじめて起動するとき

「Windows によって PC が保護されました」という青い画面が出ることがあります。exe に有料の電子署名を付けていないためです。「詳細情報」を押すと出てくる「実行」を押せば起動します。2回目からは出ません。

ショートカットキー

最初から使えるのは Ctrl+Alt+D（書き込み と マウス操作 の切り替え）だけです。ほかのアプリのショートカットを横取りしないよう、ほかの操作には最初はキーを付けていません。

ほかの操作にもキーを付けたいときは、ScreenPen のフォルダにできる savedata_user/config.json をメモ帳で開き、使いたい操作の "" の中にキーを書いて、ScreenPen を起動し直します。たとえばペンを Ctrl+Alt+P にするなら "tool_pen": "ctrl+alt+p" です。

名前動き
toggle_draw_mode書き込み と マウス操作 を切り替え（最初は Ctrl+Alt+D）
tool_pen / tool_highlighter / tool_eraserペン / 蛍光ペン / 消しゴム
tool_line / tool_arrow / tool_rect / tool_ellipse直線 / 矢印 / 四角 / 楕円
tool_text文字
undo / redo元に戻す / やり直し
clear_all全部消す
toggle_ink書いたものを隠す / 見せる
width_up / width_down線を太く / 細く（マウスのホイールでも変わります）
quick_color_1〜quick_color_9ツールバーに並んでいる9色から選ぶ（左から順に）
last_colorひとつ前の色に戻す
whiteboard / blackboardペイントを白い紙 / 黒い紙で開く
save_screenshot範囲を選んでスクリーンショット
toggle_toolbarツールバーを隠す / 見せる
quit_app終了

キーは ctrl / alt / shift と英数字などを + でつないで書きます。A〜Z の文字キーを使ったものは、ほかのアプリとぶつからないよう、書き込みモードのときだけ効きます。くわしくは zip の中の README.txt に書いてあります。

やめるとき

ScreenPen を置いたフォルダごと消せば終わりです。設定はそのフォルダの savedata_user にしか保存していません。撮ったスクリーンショットは、保存した場所に残ります。
