ScreenPen

バージョン 0.8.0（2026年11月22日）

画面の上に、そのままペンで書き込めるツールです。プレゼンや画面共有で「ここを見てください」と伝えたいときに。白い紙に描けるペイントもついています。

無料でダウンロード

Windows 10 / 11（64ビット）・ScreenPen.exe 1つで動きます・約51MB

できること

どの画面にも書き込める

スライド、ブラウザ、表計算など、いま映っている画面の上にそのまま書けます。マルチモニタにも対応。

ペン・蛍光ペン・図形・文字

手書きのペンと半透明の蛍光ペン、直線・矢印・四角・楕円、それに文字も入れられます。日本語入力もできます。

書いたら、すぐ元の操作へ

カーソルのボタンを押すと、書き込みを残したまま普段のマウス操作に戻れます。スライド送りの邪魔もしません。

書き込みごと保存

範囲を選んでスクリーンショットを撮ると、書き込んだ線も一緒に画像になります。クリップボードへのコピーも。

ペイント（白い紙・黒い紙）

白い紙や黒い紙に描けるウィンドウを開けます。ホワイトボード代わりに。PNG / JPEG で保存できます。

キーボードだけでも操作

道具の持ち替えや色の変更はショートカットキーでできます。よく使う9色はワンタッチで選べます。

画面

使い方

  1. ScreenPen.exe を好きなフォルダに置きます。設定を保存する savedata_user フォルダが exe の隣にできるので、ScreenPen 専用のフォルダを作って置くのがおすすめです。インストールは要りません。
  2. ダブルクリックで起動します。画面の上のほうにツールバーが出て、タスクトレイにもアイコンが出ます。
  3. ペンを選ぶと書けるようになります。カーソルのボタン（または Ctrl+Shift+2）で、普段のマウス操作に戻ります。
  4. 終わるときは Ctrl+Shift+Q か、タスクトレイのアイコンのメニューから終了します。

はじめて起動するときの注意

「Windows によって PC が保護されました」と出たら

ScreenPen には有料の電子署名を付けていないため、はじめて起動すると Windows の SmartScreen という確認画面が出ることがあります。ウイルスではありません。次の手順で起動できます。

  1. 青い画面の「詳細情報」を押す
  2. 下に出てくる「実行」を押す

2回目からは表示されません。心配なときは、このページのボタンからダウンロードしたものだけを使ってください。

ショートカットキー

文字キーを使うもの（L E R A T W B）は、ほかのアプリのショートカットとぶつからないように、書き込みモードのときだけ効きます。

キーできること
Ctrl+Shift+2書き込み ⇔ マウス操作 を切り替える
Ctrl+Shift+3ペン
Ctrl+Shift+4蛍光ペン
Ctrl+Shift+5消しゴム
Ctrl+Shift+L / A / R / E直線 / 矢印 / 四角 / 楕円
Ctrl+Shift+T文字
Ctrl+Shift+6 / 8元に戻す / やり直し
Ctrl+Shift+7全部消す
Ctrl+Shift+1書き込みを隠す / 見せる
Ctrl+Shift+] / [線を太く / 細く（マウスのホイールでも変えられます）
Alt+Shift+1〜9よく使う9色を選ぶ
Ctrl+Shift+9ひとつ前の色に戻す
Ctrl+Shift+W / Bペイントを 白い紙 / 黒い紙 で開く
Ctrl+Shift+PrintScreen範囲を選んでスクリーンショット
Ctrl+Shift+0ツールバーを隠す / 見せる
Ctrl+Shift+QScreenPen を終了する

キーの組み合わせは savedata_user/config.json で変えられます。

やめるとき（アンインストール）

ScreenPen を置いたフォルダごと削除すれば終わりです。設定は exe の隣の savedata_user にだけ保存していて、レジストリは使いません（撮ったスクリーンショットは、保存した場所に残ります）。
