ScreenPen

画面の上に、そのままペンで書き込めるツールです。

ScreenPen.exe をダウンロード バージョン 0.8.0 ・ 約51MB ・ Windows 10 / 11（64ビット）

どんなツールか

画面共有で説明しているときに「ここです」と丸を付けたくて作りました。画面に書き込むツールは有料のものが多かったので、自分で作ることにしました。

  • ペン、蛍光ペン、直線・矢印・四角・楕円、文字が使えます。
  • カーソルのボタンを押すと、書いたものを残したまま普段のマウス操作に戻ります。PowerPoint のスライドショー中でも、スライド送りの邪魔をしません。
  • 範囲を選んでスクリーンショットを撮ると、書き込んだ線も一緒に保存されます。
  • 白い紙・黒い紙に描ける「ペイント」のウィンドウもあります。ホワイトボード代わりに使えます。

使い方

  1. ScreenPen.exe を、ScreenPen 用に作ったフォルダに置きます。設定ファイルが入る savedata_user フォルダが exe の隣にできるためです。インストールはいりません。
  2. ダブルクリックで起動します。ツールバーと、タスクトレイのアイコンが出ます。
  3. ペンのボタンを押すと書けるようになります。カーソルのボタンで元のマウス操作に戻ります。
  4. 終わるときは Ctrl+Shift+Q か、タスクトレイのアイコンを右クリックして終了します。

はじめて起動するとき

「Windows によって PC が保護されました」という青い画面が出ることがあります。exe に有料の電子署名を付けていないためです。「詳細情報」を押すと出てくる「実行」を押せば起動します。2回目からは出ません。

ショートカットキー

文字キー（L A R E T W B）を使うものは、ほかのアプリのショートカットとぶつからないよう、書き込みモードのときだけ効きます。

キー動き
Ctrl+Shift+2書き込み と マウス操作 を切り替え
Ctrl+Shift+3 / 4 / 5ペン / 蛍光ペン / 消しゴム
Ctrl+Shift+L / A / R / E直線 / 矢印 / 四角 / 楕円
Ctrl+Shift+T文字
Ctrl+Shift+6 / 8元に戻す / やり直し
Ctrl+Shift+7全部消す
Ctrl+Shift+1書いたものを隠す / 見せる
Ctrl+Shift+] / [線を太く / 細く（マウスのホイールでも変わります）
Alt+Shift+1〜9ツールバーに並んでいる9色から選ぶ
Ctrl+Shift+9ひとつ前の色に戻す
Ctrl+Shift+W / Bペイントを白い紙 / 黒い紙で開く
Ctrl+Shift+PrintScreen範囲を選んでスクリーンショット
Ctrl+Shift+0ツールバーを隠す / 見せる
Ctrl+Shift+Q終了

キーの組み合わせは savedata_user/config.json で変えられます。

やめるとき

ScreenPen を置いたフォルダごと消せば終わりです。設定はそのフォルダの savedata_user にしか保存していません。撮ったスクリーンショットは、保存した場所に残ります。
